# Практика 6 — варіант 5 (Автосалон)

## Завдання 2

UPDATE тут доречний, а не видалення старого рядка й вставка нового, тому що
автомобіль з id = 5 — це той самий фізичний об'єкт, і його первинний ключ,
а також усі рядки в таблиці `sales`, що посилаються на нього через `car_id`,
мають залишитися пов'язаними з тим самим id; видалення й повторна вставка
створили б новий id, розірвали б ці зв'язки (або взагалі були б відхилені
через `FOREIGN KEY ... ON DELETE RESTRICT`) і без потреби порушили б
цілісність історії продажів.

## Завдання 4

Видалено рядок клієнта: `DELETE FROM clients WHERE id = 3;`
(на цього клієнта посилався рядок `sales.id = 2`).

**Прогноз:** зовнішній ключ `sales.client_id REFERENCES clients(id) ON DELETE SET NULL`
означає, що рядок клієнта видалиться без помилки, а в пов'язаному рядку
`sales` (id = 2) значення `client_id` стане NULL; сам рядок `sales` не зникне.

**Фактичний результат:** видалення пройшло успішно, рядок `sales.id = 2`
залишився в таблиці, і його `client_id` дійсно став NULL:
`(2, 6, NULL, '2026-02-18', 485000.0, 'кредит')`.

Фактичний результат повністю збігається з прогнозом — розбіжностей немає.
